# Retrieval: победители, мы, открытые направления

Состояние на эксперимент 6е. Решения по ранкеру — по среднему 5 сидов (разброс обучения ~±0.002). Цифры победителей — из докладов топ-3 на Data Fest 2026 (разбор в
прошлой сессии), лидерборд не равен нашему локальному таргету: сравнимы приросты, не уровни.
Наши цифры, если не сказано иное, — W1, 1 партиция, `exp/`.

## 2. Что делали победители и что из этого у нас

| Приём | Кто | У нас | Статус |
|---|---|---|---|
| Ранкер поверх нескольких генераторов, score/rank источников как признаки | все | CatBoost YetiRank, `*_s`/`*_r` | ✓ взято |
| RP3beta / Pixie (item → user → item), один транзит | 1, 2 | блуждание item → сущность → item, `u0` | ✓ взято |
| β-нормировка на популярность | 1 (BM25), 3 (pop^α) | β ∈ {0…1}: лучший β = 0 | ✓ закрыто, β = 0 |
| Отдельные item2item по категориям, смешанные по доле категории юзера | 3 («наибольший прирост») | сущность = юзер × cat × reg (`cr`) — граф сегментирован по категории внутри блуждания | ✓ взято, главный выигрыш (+0.031 cat, +0.008 cat+reg) |
| Co-visitation по сессиям | 1, 3 | `s24` (юзер × день) + отдельный covis top-1000 | ✓ взят как источник (вместе с BM25 +0.0035, эксп. 6е) |
| BM25 item-item | 1 | BM25 top-1000 | ✓ взят как источник (вместе с covis +0.0035, эксп. 6е); как одни признаки — шум |
| Time decay | 2 (exp, 7 дн), 3 ((1+age/14)^-p) | затухание seed-ов τ = 7 д (сетка 1…1000) | ✓ на seed-ах; **на рёбрах графа — нет** |
| Novelty-фильтр (без виденного) | все | да, по любым событиям вкл. показы | ✓ |
| Freshness-фильтр (item без активности 5 дн — вон) | 3 | нет; лимит CAP — свежие сущности | **открыто** |
| Frontier-обрезка промежуточного шага | 2 (~600) | параметр есть в `walk`, не тюнился | **открыто** |
| Глубина пула: тысячи кандидатов, ~5k лучше ~10k | 1 | top-1000 на источник ✓ (+0.006–0.007), 2000 — решено не брать | ✓ закрыто |
| Клики важнее контактов для генерации | 1 | w_contact 1 ≈ 3 > 10; показы с весом 0.3 обязательны | ✓ закрыто |
| Бакетные генераторы (популярное в cat × reg, sid_0 × reg) | 1 (R@5000 0.15–0.20, слабый top-160) | bp (cat × reg) — в шуме; **sp (s0 × loc, по аффинити) +0.002–0.004** | ✓ sp берём (⇧) |
| ALS / EASE / SVD / SLIM / two-tower | все пробовали | ALS в старом пайплайне — слабый | ✗ закрыто (у всех слабо) |
| Sequence-модель | 1 (+0.001–0.004, как признаки, не источник) | нет | открыто, дорого, мало |
| Больше обучающих юзеров, квоты как в eval | 1 («явно бустило») | на сервере ранкер учится на всех юзерах окна W1 | ✓ за счёт объёма |

## 3. Куда теряются таргеты (эксп. 6, 6б, 1%)

| Класс | Доля | Что это | Что закрывает |
|---|---|---|---|
| Найдены (top-160) | ~13% | | |
| Потеряны ранкером | ~5% | в пуле, ниже 160 | признаки ранкера, сложные негативы |
| C — за отсечкой | 11.5% | путь есть, ранг > 500 | ✓ глубина 1000 (+4.2 п. потолка) |
| **B — недостижим** | **52%** | хвост в своих сегментах: 82% — в категории из истории, у item медиана 2 юзера | sp: ~2 п.; остальное открыто |
| A3 — нет в графе | 12% | в universe, без событий за 28 дней | сжимается с объёмом (12 → 7% при ×2) |
| U — нет истории | 6% | у юзера нет событий за 28 дней | cro (старая история) — не помогает; открыто |
| Холодные item | 0% | исключены определением таргета | не нужно |

Главное: **B — структурный промах одношагового блуждания, не артефакт 1%** (при ×2 данных
доля B растёт: A3 переходит в B). Пути через совместные просмотры (covis, BM25, RP3 с любыми
весами) до B почти не доходят — у item мало общих юзеров с историей. covis и BM25 всё же полезны
ранкеру (+0.0035), но за счёт качества пула, а не охвата B. Для B нужен сигнал, не зависящий от
совместных просмотров.
